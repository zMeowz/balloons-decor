# 🎈 Balloons Decor ZP

Сайт-візитка сервісу преміальних фотозон та декору у Запоріжжі.
Двомовний (укр/рус), з портфоліо, формою заявок у Telegram та адмін-панеллю.

> **Ти новачок?** Не хвилюйся. Уся покрокова інструкція «як запустити з нуля» —
> у файлі **[SETUP.md](./SETUP.md)**. Читай саме його. Цей файл — короткий технічний огляд.

---

## Що вміє сайт

- **Головна** — банер з відео/паралаксом, послуги, колода робіт (свайп), ціни, процес, відгуки, форма.
- **Роботи** — портфоліо з фільтром за категоріями (наповнюється з адмінки → зростає SEO).
- **Про Аню** — сторінка майстра з фото та історією.
- **Контакти** — способи звʼязку + форма заявки.
- **Адмінка** (`/admin`) — керування роботами, цінами, контактами; перегляд заявок.
- **Заявки** — миттєво летять у Telegram і зберігаються в базі.
- **Двомовність** — українська (основна) + російська, з перемикачем.
- **SEO** — метадані, sitemap.xml, robots.txt, мікророзмітка LocalBusiness.

## Технології

| Що | Навіщо |
|---|---|
| **Next.js 14** (App Router) | Каркас сайту, швидкість, SEO |
| **Supabase** | База даних + сховище фото + дані для адмінки |
| **Telegram Bot API** | Заявки в месенджер |
| **Vercel** | Хостинг (безкоштовний тариф на старті) |
| Звичайний CSS | Авторський дизайн без важких бібліотек |

## Команди

```bash
npm install       # встановити залежності (один раз)
npm run dev       # локальний запуск для розробки → http://localhost:3000
npm run build     # зібрати продакшн-версію
npm start         # запустити зібрану версію
```

## Важливо про демо-режим

Сайт працює **навіть без налаштувань** — показує демо-роботи й ціни з файлу
`src/lib/seed.js`. Щойно підключиш Supabase (див. SETUP.md) — сайт почне показувати
твої реальні дані з адмінки. Нічого переписувати не треба.

## Структура проєкту (коротко)

```
src/
  app/
    [locale]/        сторінки сайту (uk/ru): головна, works, about, contact
    admin/           адмін-панель + серверні дії (actions.js)
    api/             обробники: /api/lead (заявки), /api/admin/* (вхід)
    layout.js        кореневий каркас (шрифти, <html>)
    globals.css      уся дизайн-система
  components/        Header, Footer, Hero, StackedDeck, LeadForm, ...
  i18n/              мови та всі тексти (dictionaries/uk.js, ru.js)
  lib/               data.js, supabase.js, seed.js, auth.js
  middleware.js      мовний роутинг (/ → /uk)
supabase/schema.sql  SQL для створення бази
public/              фото, favicon, (сюди клади hero.mp4 та anya.jpg)
legacy/              стара статична версія (просто архів)
```

## Куди класти медіа

- `public/media/hero.mp4` — зʼявиться автоматично як відео на банері.
- `public/media/anya.jpg` — фото Ані на сторінці «Про нас».
- Фото робіт додаються через адмінку (завантажуються в Supabase).
