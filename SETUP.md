# 🚀 Запуск сайта Balloons Decor — пошагово для новичка

Привет! Это инструкция «с нуля». Не нужно ничего знать о программировании —
просто делай по шагам. Если где-то застрял — напиши мне, разберём.

Весь путь займёт примерно **1–1.5 часа**. Разбит на 6 этапов:

1. Telegram-бот (заявки в телефон) — 5 мин
2. Supabase (база данных + фото) — 20 мин
3. Vercel (публикация сайта) — 15 мин
4. Переменные окружения (ключи) — 10 мин
5. Домен (адрес сайта) — 15 мин
6. Реклама Google и Meta — позже, когда сайт уже живой

> 💡 **Что уже готово:** сам сайт полностью написан и работает. Даже если ничего
> из этого не настроить — сайт откроется и покажет демо-контент. Настройки нужны,
> чтобы заработали *твои* фото, заявки и админка.

## 🟦 Этап 1. Telegram-бот (куда будут падать заявки)

1. Открой Telegram, в поиске найди **@BotFather** (с синей галочкой).
2. Напиши ему `/newbot`.
3. Придумай имя бота (например `Balloons Decor Заявки`).
4. Придумай username бота — должен заканчиваться на `bot` (например `balloons_decor_leads_bot`).
5. BotFather пришлёт **токен** — длинную строку вида `123456789:AAxx...`.
   **Скопируй и сохрани её** — это `TELEGRAM_BOT_TOKEN`.

**Теперь нужен твой chat_id** (куда слать сообщения):

6. Найди в Telegram бота **@userinfobot**, нажми Start — он пришлёт твой `Id` (число).
   Это `TELEGRAM_CHAT_ID`.
7. **Важно:** зайди в чат со своим новым ботом и нажми **Start** (иначе он не сможет тебе писать).

> Хочешь, чтобы заявки видела вся команда? Создай группу, добавь туда бота,
> и используй id группы (для групп есть чуть другой способ — напиши мне, помогу).

---

## 🟩 Этап 2. Supabase (база данных, фото, админка)

1. Зайди на **[supabase.com](https://supabase.com)** → **Start your project** → войди через GitHub или email.
2. Нажми **New project**. Заполни:
   - Name: `balloons-decor`
   - Database Password: придумай надёжный (сохрани его на всякий случай).
   - Region: выбери ближайший (например Frankfurt).
3. Подожди ~2 минуты, пока проект создаётся.

**Создаём таблицы:**

4. Слева выбери **SQL Editor** → **New query**.
5. Открой в нашем проекте файл `supabase/schema.sql`, **скопируй всё** и вставь в редактор.
6. Нажми **Run** (справа снизу). Должно написать `Success`.

**Создаём хранилище для фото:**

7. Слева выбери **Storage** → **New bucket**.
8. Название: `works`. Обязательно включи галочку **Public bucket**. Создай.

**Забираем ключи:**

9. Слева **Project Settings** (шестерёнка) → **API**.
10. Скопируй и сохрани три значения:
    - **Project URL** → это `NEXT_PUBLIC_SUPABASE_URL`
    - **anon public** ключ → это `NEXT_PUBLIC_SUPABASE_ANON_KEY`
    - **service_role** ключ → это `SUPABASE_SERVICE_ROLE_KEY`
      ⚠️ Это секретный ключ! Никому не показывай и не выкладывай в интернет.

## 🟪 Этап 3. Vercel (публикация сайта в интернете)

1. Зайди на **[vercel.com](https://vercel.com)** → **Sign up** через **GitHub**.
2. Нажми **Add New… → Project**.
3. Найди в списке репозиторий **balloons-decor** → **Import**.
   - Если его нет — сначала нужно, чтобы код был на GitHub (он уже туда отправлен мной,
     в ветку разработки; для боевого сайта используем основную ветку — напиши, помогу слить).
4. Vercel сам поймёт, что это Next.js. **Пока не нажимай Deploy** — сначала добавь ключи (Этап 4).

---

## 🔑 Этап 4. Переменные окружения (вставляем ключи)

На странице импорта в Vercel (или потом в **Settings → Environment Variables**)
добавь такие переменные (имя → значение):

| Имя переменной | Значение |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Project URL из Supabase |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | anon public ключ |
| `SUPABASE_SERVICE_ROLE_KEY` | service_role ключ |
| `ADMIN_PASSWORD` | пароль, которым ты будешь входить в `/admin` (придумай сложный) |
| `ADMIN_SESSION_SECRET` | любая длинная случайная строка (набери 40+ символов) |
| `TELEGRAM_BOT_TOKEN` | токен из BotFather |
| `TELEGRAM_CHAT_ID` | твой id из userinfobot |
| `NEXT_PUBLIC_SITE_URL` | адрес сайта, напр. `https://balloonsdecor.com.ua` |

Затем нажми **Deploy**. Через пару минут сайт будет доступен по адресу вида
`balloons-decor-xxxx.vercel.app`.

> После добавления Supabase-ключей вернись в `next.config.mjs` — там уже разрешён
> хост `*.supabase.co`, так что фото из хранилища будут показываться. Дополнительно
> ничего менять не нужно.

**Проверь, что всё работает:**
- Открой сайт → должен открыться на украинском.
- Открой `/admin` → введи `ADMIN_PASSWORD` → попадёшь в панель.
- Добавь одну работу с фото → она появится на сайте.
- Отправь тестовую заявку через форму → должна прийти в Telegram. ✅

## 🌐 Этап 5. Домен (красивый адрес сайта)

1. Купи домен у регистратора (например **[imena.ua](https://imena.ua)**, **[nic.ua](https://nic.ua)**,
   **[hostiq.ua](https://hostiq.ua)**). Домен `.com.ua` стоит ~200–400 грн/год.
   Хорошие варианты: `balloonsdecor.com.ua`, `balloons-decor.zp.ua`.
2. В Vercel: **Settings → Domains → Add** → введи свой домен.
3. Vercel покажет, какие **DNS-записи** прописать (обычно один `A`-запись или `CNAME`).
4. Зайди в панель регистратора домена → раздел DNS → добавь записи, которые показал Vercel.
5. Подожди от 10 минут до нескольких часов — домен подключится, HTTPS включится автоматически.
6. Обнови переменную `NEXT_PUBLIC_SITE_URL` на свой домен и сделай **Redeploy**.

## 📈 Этап 6. Реклама Google и Meta (когда сайт уже живой)

Сайт уже готов принимать пиксели — нужно только вставить ID.

**Google Analytics / Google Ads:**
1. Создай аккаунт [Google Analytics 4](https://analytics.google.com), получи `G-XXXXXXX`.
2. Добавь переменную `NEXT_PUBLIC_GA_MEASUREMENT_ID` = твой `G-XXXXXXX`.
3. Для Google Ads — свяжи Ads с Analytics, настрой цель «отправка заявки».

**Meta (Facebook/Instagram) Pixel:**
1. В [Meta Business](https://business.facebook.com) → Events Manager → создай пиксель, получи ID.
2. Добавь переменную `NEXT_PUBLIC_META_PIXEL_ID` = ID пикселя.

> 🔧 Код подключения пикселей я добавлю по твоему сигналу — так мы не тормозим сайт
> лишними скриптами до старта рекламы. Дай знать, когда будешь запускать кампании.

## ❓ Частые вопросы

**Заявки не приходят в Telegram.** Проверь: нажал ли ты Start в чате с ботом;
правильные ли `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`; сделал ли Redeploy после
добавления переменных.

**Фото не отображаются.** Bucket `works` должен быть **Public**. Проверь галочку в Supabase → Storage.

**Не пускает в админку.** Проверь `ADMIN_PASSWORD` в переменных Vercel и сделай Redeploy.

**Хочу поменять тексты.** Тексты лежат в `src/i18n/dictionaries/uk.js` и `ru.js`.
Либо часть (контакты) меняется прямо в админке.
